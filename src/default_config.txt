# URL Router configuration
#
# Each line is:   <pattern>   <browser>
# Rules are checked top to bottom and the FIRST match wins, so put specific
# rules above general ones and keep the catch-all  *  last.
#
# Patterns
#   youtube.com                 that site and every subdomain (www., m., music.)
#                               on http or https
#   docs.google.com/document    that site, only paths starting with /document
#   https://github.com/my-org   anything containing :// is a plain prefix of the
#                               full URL (case-insensitive)
#   *                           everything else
#
# Browsers
#   chrome  firefox  edge  brave  vivaldi  opera  librewolf
#       found automatically wherever they're installed
#   "C:\Path\To\browser.exe"
#       any program; put quotes around paths with spaces
#   Anything after the browser is passed as extra arguments, e.g.
#       example.com   firefox -private-window
#   The URL is added as the last argument, or put %URL% where it should go:
#       example.com   chrome --app=%URL%
#   %ENVIRONMENT% variables such as %LOCALAPPDATA% are expanded.
#
# Named browsers (optional), for profiles or reuse:
#   browser work "C:\Program Files\Mozilla Firefox\firefox.exe" -P Work
#   github.com/my-company   work
#
# Slack (optional): open Slack links in the Slack app instead of a browser
# tab. Links it can't open in the app continue to the next rule. Links like
# https://acme.slack.com/... need the workspace's team ID, which you can see
# in the address bar (app.slack.com/client/T0123ABCD/...) when you open the
# workspace in a browser:
#   slack-team  acme  T0123ABCD
#   slack.com   slack
#
# Lines starting with # are comments. Changes take effect on the next click;
# no restart needed. Try a URL without opening it:
#   urlrouter.exe --test https://www.youtube.com/

youtube.com     firefox
youtu.be        firefox

*               chrome
